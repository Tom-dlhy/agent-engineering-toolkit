Read narrow framework skill, then only relevant references. Do not
load all 21 leaves for one UI change. UI component libraries remain
under UI, design decisions under Design, backend authorization under
Backend/Quality and cloud deployment under Cloud.

Universal check: pinned framework/runtime, SSR versus CSR/static,
authorization at every server endpoint, serialized/private caching,
input validation, hydration, accessibility, performance and actual
production build/browser tests. Do not select based on framework hype.
