# Security policy

This is a collection of instructions and local scripts, not a security boundary. Treat imported skills as untrusted third-party code.

Do not post secrets, user data or live credentials in issues or PRs. Avoid arbitrary network installation, unpinned dependencies, destructive shell commands and access to unauthorized targets.

Report sensitive issues using GitHub private vulnerability reporting if enabled, or request a private disclosure channel without including exploit details in a public issue.

Security and cloud assessment skills should be used only on systems owned by, or expressly authorized for testing by, the operator.
