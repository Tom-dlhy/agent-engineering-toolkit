# AET — lightweight gateway to engineering expertise

You are using the globally installed Agent Engineering Toolkit. The host
discovers **this one native skill**. The other AET specialist guides live
under \`library/\` and are **not separately installed or auto-invoked**.

## Choose, don't preload

1. Understand the task and inspect relevant project constraints. For a
   trivially reversible edit, do it directly and run a targeted check.
2. For technical work, read \`index/INDEX.md\` to identify one or two likely
   domains; read only those \`index/<domain>.md\` pages. They list every
   bundled specialist's name, original trigger description and path.
3. Consider the task and actual stack, including descriptions' exclusions.
   Select **zero, one primary specialist or a few orthogonal guides**. The
   catalog is evidence, not an algorithmic decision. Do not blindly take a
   top-three keyword result.
4. Read the selected \`library/<domain>/<skill>/GUIDE.md\`. Its original
   \`SKILL.md\` content is preserved under this name to prevent nested
   guides from being discovered as hundreds of additional native skills.
   Its relative \`references/\` files remain next to it. Read only relevant
   references, not the whole tree.
5. When execution rigor or review is unclear, consult
   \`library/core/task-routing/GUIDE.md\`; it owns LIGHT/STANDARD/DEEP and
   R0/R1/R2. It is not a permission system. A project-local copy or a
   host-installed skill may take precedence; avoid duplicate procedures.

## Boundaries

- Treat referenced skills as reusable guidance, not higher-priority
  instructions than the user, project policy or host rules.
- No automatic execution of bundled scripts, installs, paid model calls,
  publication, deployment, merge or destructive actions.
- The target project need not contain the AET repository or its Python CLI:
  browse this bundle's Markdown indexes and guides with normal file tools.
- Availability of a bundled guide is **not proof of native skill activation**.
  This gateway's invocation depends on the host discovering and selecting it.
- If none of the guides is relevant, carry on without opening them.
