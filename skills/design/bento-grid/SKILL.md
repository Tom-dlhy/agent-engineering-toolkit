# bento-grid

## Composition
Create a small hierarchy of differently sized tiles tied to actual content priority. Keep heading, body, visual and action aligned; use stable responsive grid spans rather than random arrangements.
## Responsive
At small widths, turn complex arrangements into a logical reading order. Ensure keyboard/focus order follows DOM rather than visual tricks. Avoid cards with invisible interactions or ambiguous hover-only controls.
## Visual QA
Ensure empty and long states fit, shadows and radii remain coherent, and tile illustrations convey a specific feature. Use consistent internal spacing and contrast.
## Exit
Verify that the grid improves scanning time and comprehension; fall back to an editorial list when features need more explanation.
