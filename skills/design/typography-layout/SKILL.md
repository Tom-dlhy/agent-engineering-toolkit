# typography-layout

## Reading flow
Identify primary user goal, content priority, reading width and intentional visual rhythm. Choose a type scale with predictable line heights and fluid sizes; avoid combining too many font families or weights.
## Layout
Build responsive grids with semantic grouping, negative space and purposeful alignment. Balance asymmetry with consistent anchors. Use content-led breakpoints, cap line lengths and test longer translated labels.
## Performance
Prefer locally hosted/subset font assets where licensing permits, font-display behavior suited to UX, and layout stability; check Cumulative Layout Shift.
## QA
Inspect navigation, headings, paragraphs, forms, cards, empty states and narrow screens. Test zoom at 200%, readable contrast and headings order.
