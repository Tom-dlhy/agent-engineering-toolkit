# Brand identity visualization — art direction and delivery checks

**Read when:** producing a rendered brand-board image, presentation, logo-direction board or reviewing one for practical use.

## Before rendering
Write a brief with **subject**, **target viewer**, **goal**, **existing brand constraints**, **primary concept**, **composition/layout**, **typography roles**, **color roles**, **logo variants** and **imagery style**. Decide output format: rendered inspiration board vs editable assets. Do not generate a rendered image unless requested; for code-ready design tokens, prefer design-system.

### Example board specification
Purpose: test a maritime family supply brand identity. Layout: a coherent six-panel grid: wordmark/icon, application on uniform, document cover, color system, real photographic direction and compact mobile header. Keep plenty of whitespace, restrained typographic labeling and large enough type to read; no made-up partner badges or unrelated ocean clichés. Preserve existing logo if the task is an identity extension.

## Deliverable fidelity matrix
| Artifact | Can a rendered concept board provide it? | Additional work |
|---|---|---|
| Visual direction / color inspiration | Yes | Compare with brand/product constraints |
| Concept logo | Inspiration only | Vector recreation, originality and legal checks |
| Editable SVG logo / icon | No | Actual vector editor/source |
| Brand token file | No | Convert approved palettes into design system |
| Accessibility compliance | No | Contrast/keyboard/usability verification on real interface |
| Commercial font license | No | License review and asset management |

## Review loop
1. Mark existing vs conceptual/fictional symbols and words.
2. Verify composition, gutters, symbolic consistency and hierarchy without depending on glossy mockups.
3. Test black/white version, tiny app icon, dark/light backgrounds and printed low-contrast mode.
4. Check text is accurate and legible; image generation may hallucinate type.
5. Compare multiple application touchpoints for identity continuity.
6. Record approved direction and editables still required; do not claim a concept grants exclusive ownership of a symbol.

## Avoid
Dark charcoal as an automatic premium choice; cinematic noise over legibility; misleading trademark claims; imaginary endorsements; copying recognizable brand marks or proprietary photography; outputting a picture when the user asked for machine-editable brand assets.
