# brand-identity-visualization

## Purpose
Turn brand strategy into coherent **visual identity concepts** and review their consistency. Separate exploration/rendered moodboards from **production assets**: a convincing board is not proof of usable vector files, registered marks or accessible interface design.

## Route the task
1. Identify brand promise, audience, market/cultural setting, personality, references, existing logo, forbidden motifs and usage channels; preserve established branding by default.
2. Choose an identity direction with clear symbolic rationale and contrast to generic competitor imagery. Do not equate premium with dark monochrome or oversized mockups.
3. Specify palette roles, typographic character, logo geometry, mark/wordmark relationships, materials/imagery and UI translation.
4. If the user explicitly requests a rendered image/brand board and an image generator is available, provide a compact art-directed brief to that tool. If actual editable logo/vector assets are required, use appropriate editable tooling rather than claiming an image is sufficient.
5. Review at small size, monochrome, dark/light applications and culturally appropriate contexts; never claim trademark clearance without a search by qualified counsel.

- [Brand board production and QA](references/board-production-and-qa.md) — **read when** generating or reviewing a moodboard, logo concept sheet or presentation-ready visual system.

## Boundaries
Use design-system for implementation tokens/components, frontend-design for websites, typography-layout for page typography and UX-audit for usability. No default image generation for text-only requests, and no import of upstream generator scripts.
