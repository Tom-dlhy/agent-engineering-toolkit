# stack-advisor

## Intake
Identify product audience, SEO/SSR, expected traffic, team capability, compliance, CRUD vs compute intensity, time to market, deployment constraints and exit requirements. Check whether an existing stack should be retained.
## Options
Propose a minimal viable stack, a scalable alternative and at least one credible rejected alternative. Evaluate frameworks, UI library, validation, database/ORM, hosting, queue, observability and CI only as needed.
## Score
Compare implementation effort, ecosystem maturity, operational burden, performance, cost, security, portability and talent availability. Keep weights explicit.
## Output
Recommendation, architecture diagram, dependency list, first deployment plan, cost caveats, and a short ADR. Validate version-sensitive ecosystem claims via official docs.
